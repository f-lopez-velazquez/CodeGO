🧩 Integración en Cognago y Cursos a Distancia

Puedes integrar el entorno de programación y certificación de CodeGO en cualquier plataforma web (Cognago, Moodle, Canvas, o tu propio LMS) utilizando el SDK autónomo codego-sdk.js:

<!-- 1. Incluir el SDK en tu plataforma -->
<script src="codego-sdk.js"></script>

<!-- 2. Contenedor HTML -->
<div id="mi-editor-cognago" style="height: 520px;"></div>

<!-- 3. Inicializar entorno -->
<script>
  const env = CodeGOSDK.createCodeGOEnvironment({
    container: '#mi-editor-cognago',
    language: 'python', // 'cpp' | 'java' | 'javascript' | 'r'
    mode: 'task',       // 'task' | 'exam' | 'activity'
    student: { name: 'Alumno Cognago', id: 'CG-8821' },
    subject: 'Programación para Cursos a Distancia',
    onSubmission: (entrega) => {
      console.log('Sello HMAC:', entrega.hmacSignature);
      console.log('Reporte forense:', entrega.telemetry);
      // Enviar a la API de Cognago para calificar automáticamente
    }
  });
</script>
