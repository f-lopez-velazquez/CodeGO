      Ejecutar y responder a input()
      Pulsa F5 o Ejecutar. Cuando Python muestre una pregunta, el cursor aparece en esa misma línea de la terminal. Escribe la respuesta y pulsa Enter.
      Detener cancela el programa actual. Limpiar borra el historial visual, sin cerrar el proceso que esté esperando entrada.
      
        
      Imágenes, sonidos, CSV y otros archivos
      Guarda los recursos dentro de la carpeta del proyecto. codeGO ejecuta cada archivo con su propia carpeta como directorio de trabajo, por lo que pygame.image.load("recursos/nave.png") funciona igual en Windows, macOS y Linux.
      from pathlib import Path
BASE = Path(__file__).resolve().parent
imagen = BASE / "recursos" / "nave.png"
sonido = BASE / "recursos" / "salto.wav"
      Los archivos binarios aparecen en el explorador como recursos y no se abren como texto para evitar dañarlos.
      
        
      Arduino, ESP32 y puertos seriales
      Conecta la placa por USB, cierra el Monitor Serial de otras aplicaciones y vuelve a comprobar los puertos. En Windows, algunas placas clon requieren el controlador CH340 o CP210x del fabricante; Arduino Uno original suele usar el controlador del sistema. SMBus2 controla I²C directamente en Raspberry Pi y otros sistemas Unix compatibles; en Windows usa una placa mediante puerto serial.
      from serial.tools import list_ports
import serial
puertos = list(list_ports.comports())
print([p.device for p in puertos])
with serial.Serial(puertos[0].device, 9600, timeout=2) as placa:
    print(placa.readline().decode(errors="replace"))
      Para PyFirmata2, carga primero StandardFirmata desde Arduino IDE. Para ESP32 puedes instalar esptool desde el gestor cuando necesites flashear firmware.
      
        
      Errores frecuentes y cómo leerlos
      SyntaxError marca una instrucción mal escrita; por ejemplo, pimport pygame debe ser import pygame. ModuleNotFoundError indica el nombre de una librería ausente. FileNotFoundError suele indicar una ruta incorrecta: usa Path(__file__) como en la guía de archivos.
      Lee la última línea roja y después revisa el archivo y número de línea mostrados arriba.
      
        
      Modos para clase, tarea y examen
      Actividad permite explorar libremente proyectos. Tarea certifica autoría y bloquea pegado externo. Examen activa el entorno supervisado y la entrega sellada. El profesor debe elegir el modo adecuado antes de iniciar.
